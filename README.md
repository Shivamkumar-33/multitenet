# OrgSift – AI Document Analysis Platform

OrgSift is a multi-tenant SaaS platform that helps organizations manage documents and analyze them using AI.

## Features
- Organization-based workspaces
- Secure authentication with Clerk
- Document upload and management
- AI-powered summarization and question answering
- Sentiment analysis and entity extraction
- Cloud file storage

## Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes
- **Database:** PostgreSQL, Prisma ORM
- **Authentication:** Clerk
- **AI:** Google Gemini
- **Storage:** Vercel Blob

## Getting Started

```bash
git clone <your-repository-url>
cd OrgSift
npm install
npm run dev
```

Configure your environment variables in `.env.local` before running the application.
